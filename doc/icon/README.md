# beebread icons

| File | Use |
|---|---|
| `beebread.svg` | Main logo, for light backgrounds |
| `beebread-dark.svg` | Same logo for dark backgrounds |
| `beebread-small.svg` | Simplified logo for 32 px and smaller (favicons, badges) |
| `png/` | PNG exports at fixed sizes, transparent background |
| `avatar-*.png` | 500 x 500 on white, for GitHub avatars and social previews |

In a README:

```html
<img src="doc/icon/beebread.svg" alt="beebread" width="96">
```
